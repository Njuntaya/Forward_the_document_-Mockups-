ระบบคำร้องขอเอกสารสำหรับนักศึกษา (Student Document Request System)
================================================================================
ไฟล์ในชุด Mockup (Sprint 2 Frontend & Dashboard):
1. index.html - โครงสร้างหน้าเว็บ (หน้าระบบ Login, หน้ายื่นคำร้องของนักศึกษา, หน้าแดชบอร์ดเจ้าหน้าที่)
2. style.css - การตกแต่งความสวยงาม ฟอนต์ Sarabun, ดีไซน์แบบ Modern & Responsive
3. app.js - ตรรกะการจำลองระบบ (State management, บันทึกข้อมูลผ่าน LocalStorage, อนุมัติ/ปฏิเสธคำร้อง)

วิธีเปิดใช้งาน:
- วิธีที่ 1: ดับเบิลคลิกเปิดไฟล์ index.html ด้วย Web Browser ใดก็ได้ (Google Chrome, Edge, Safari)
- วิธีที่ 2: เปิดโฟลเดอร์นี้ใน VS Code แล้วคลิกปุ่ม "Go Live" เพื่อรัน Live Server ได้ทันที

ฟีเจอร์ที่มีในระบบตาม T2.1 และ T2.3:
- (T2.3) เลือกระบบระหว่าง "นักศึกษา" และ "เจ้าหน้าที่ทะเบียน" พร้อมระบบจำลองการเข้าสู่ระบบ
- (T2.1) ระบบยื่นคำร้องขอเอกสาร เลือกประเภทเอกสาร ระบุจำนวนและเหตุผล (UI/JS)
- ตารางประวัติการยื่นคำร้องของนักศึกษา
- (T2.3) แดชบอร์ดเจ้าหน้าที่: ดูสถิติจำนวนคำร้อง (รอตรวจสอบ/อนุมัติ/ปฏิเสธ)
- การกรองสถานะคำร้อง
- ปุ่มกด "อนุมัติ" หรือ "ปฏิเสธ" (มีกล่องกรอกเหตุผลการปฏิเสธ) พร้อมอัปเดตแบบเรียลไทม์
